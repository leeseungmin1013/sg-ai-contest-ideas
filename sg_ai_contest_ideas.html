7개 아이디어 상세

각 카드는 발표 자료로 바로 옮길 수 있도록 한 줄 요약, 기능, MVP, 차별화 포인트 중심으로 구성했습니다.

1

소크라테스형 AI TA

정답 코드를 대신 작성하지 않고, 학생이 오류 원인과 개념을 스스로 발견하도록 돕는 AI 조교.

문제

  • 밤늦게 과제 오류나 수식 이해에 막혀도 질문할 곳이 부족합니다.
  • 일반 ChatGPT는 정답을 바로 제공해 학습 과정이 생략될 수 있습니다.

주요 기능

  • 강의 계획서와 실습 가이드라인 기반 답변
  • 오류 메시지 해석, 개념 확인, 의심 코드 위치 안내
  • 실패 횟수에 따라 점진적으로 구체화되는 힌트
  • 익명화된 공통 오류 리포트 제공

MVP

  • Python 기초 과목 1개 대상
  • 코드, 오류 메시지, 과제 설명 입력
  • 단계형 힌트와 개념 질문 출력
학습 지원 AI 리터러시 최우선 후보
2

Reading Pace AI

페이지 수가 아니라 학생의 사전지식과 이해 속도에 맞춰 학습 계획을 재조정하는 매니저.

문제

  • 같은 10쪽이라도 학생마다 필요한 시간과 난이도가 다릅니다.
  • 기존 플래너는 일정은 관리하지만 이해도를 반영하지 못합니다.

주요 기능

  • 사전지식 진단 퀴즈
  • 비선형 독서 플랜 생성
  • 1분 이해도 체크와 페이스 재조정
  • 시험기간 회피 행동에 대한 공감형 코칭

MVP

  • PDF 교재 또는 강의노트 업로드
  • 3일·7일·14일 학습 계획 생성
  • 이해도 퀴즈 기반 다음 계획 수정
적응형 학습 예습·복습
3

실시간 수강·전공 설계 에이전트

졸업요건, 자기설계전공, 시간표, 선수과목, 진로 목표를 함께 고려해 학기 전략을 제안합니다.

문제

  • 수강신청은 졸업요건, 시간표 충돌, 경쟁률, 진로를 동시에 고려해야 하는 퍼즐입니다.
  • 정보가 여러 시스템과 문서, 선배 조언에 흩어져 있습니다.

주요 기능

  • 졸업요건 자동 점검
  • 희망 강의와 공강 선호를 반영한 시간표 조합
  • 자기설계전공 플래너
  • 대체 과목과 수강신청 플랜 B 제공
  • 우연성 추천 기능인 수강신청 타로

MVP

  • 특정 전공 1~2개부터 시작
  • 이수 과목 수동 입력
  • 시간표 후보 3개와 졸업요건 리포트 제공
수강신청 자기설계전공 학생 체감도 높음
4

서강 규정 GPT

학칙, 내규, 장학, 등록금 환불, 휴복학 규정을 조항·페이지 근거와 함께 답하는 RAG 챗봇.

문제

  • 규정 문서가 여러 PDF와 웹페이지에 흩어져 있습니다.
  • 학생과 행정 직원 모두 케이스별 근거 조항을 찾는 데 시간이 걸립니다.

주요 기능

  • 학사·장학·환불·휴복학 규정 통합 인덱싱
  • 문서명, 조항, 페이지, 링크 인용
  • 학생용 쉬운 설명과 직원용 처리 근거 모드
  • 담당 부서 확인 필요 플래그

MVP

  • 휴학, 복학, 장학, 등록금 환불 4개 영역
  • PDF 업로드 기반 RAG
  • 답변 출처 표시 필수
행정 효율 RAG 근거 인용
5

내 취향 알바트로스

동아리, 세미나, 비교과, 장학, 공모전, 채용 설명회를 학생 관심사에 맞춰 추천하는 피드.

문제

  • 유용한 공지가 많지만 채널이 흩어져 있어 놓치기 쉽습니다.
  • 주최자는 홍보 효율이 낮고, 학생은 자신에게 맞는 기회를 찾기 어렵습니다.

주요 기능

  • 공지 자동 수집·정규화
  • 관심사와 전공 기반 추천
  • 세미나, 동아리, 장학, 공모전, 연구실 분류
  • 학제간 연구자·멘토 매칭 확장

MVP

  • 학교 공식 공지와 학과 공지 일부 수집
  • 관심 키워드 5개 기반 추천
  • 주간 개인화 뉴스레터 생성
캠퍼스 정보 개인화 피드
6

알바트로스 커리어 멘토

이력서, GitHub, 관심 직무, 성향을 분석해 부족 역량과 교내 자원, 선배 사례를 연결합니다.

문제

  • 학생은 어떤 역량을 더 준비해야 하는지 알기 어렵습니다.
  • 비슷한 출발점의 선배 사례는 유용하지만 접근성이 낮습니다.

주요 기능

  • 이력서, GitHub, 수강 과목 기반 역량 진단
  • 비교과, 강의, 연구실, 공모전 추천
  • 유사 선배 진로 사례 제시
  • 직무별 모의 면접과 Future Self 코칭

MVP

  • 학생 프로필 수동 입력
  • 이력서 텍스트 분석
  • 직무별 역량 체크리스트와 비교과 매칭
진로 동문 연결 모의면접
7

AI 시대 평가·협업·정책 인사이트

팀플, 보고서, 강의 이해도, 학사 정책을 데이터 기반으로 진단하는 교수자·행정용 플랫폼.

문제

  • AI 사용을 금지하기보다 어떻게 사용했는지 평가하는 기준이 필요합니다.
  • 팀플 무임승차, 인용 누락, 묻지 못한 질문, 정책 영향은 기존 방식으로 파악하기 어렵습니다.

주요 모듈

  • 팀플 코파일럿: 회의록, 액션 아이템, 기여도 신호
  • AI 사용 가시화 평가: 프롬프트와 수정 과정 평가
  • claim 검증: 보고서 주장과 출처 대조
  • 묻지 못한 질문 큐레이터: 익명 질문 클러스터링
  • 정책 시뮬레이터: 정책 변화의 학생군별 영향 예측

MVP

  • 묻지 못한 질문 큐레이터 또는 AI 사용 가시화 평가 중 하나로 축소 권장
  • 프라이버시와 공정성 원칙을 발표에 명확히 포함
평가 혁신 협업 정책

최종 후보 추천

공모전 완성도 기준으로는 메인 아이디어를 하나로 좁히고, 나머지를 확장 가능성으로 보여주는 전략이 가장 안정적입니다.

1순위: 소크라테스형 AI TA

학습 지원·AI 활용 교육 분야와 직접 맞고, 공익성·차별성·구현 가능성의 균형이 가장 좋습니다.

2순위: 수강·전공 설계 에이전트

학생 체감도가 높고 서강의 자기설계전공, 융합 교육 이미지와 연결하기 좋습니다.

3순위: 서강 규정 GPT

행정 효율 개선 효과가 명확합니다. 근거 인용과 직원용 모드를 강조해야 차별화됩니다.

4순위: 평가·협업 인사이트

시대성과 차별성은 강하지만 평가 공정성, 프라이버시 설계가 발표의 핵심 리스크입니다.

Python 기초 과목 MVP

오류 메시지 해석, 단계형 힌트, 공통 오류 리포트로 가장 작은 실사용 단위를 만듭니다.

Reading Pace 연동

예습·복습 계획, 이해도 퀴즈, 개념 보충 자료를 연결해 학습 루프를 완성합니다.

AI 사용 가시화 평가

프롬프트 로그와 수정 과정을 통해 단순 복붙이 아닌 비판적 AI 활용을 평가합니다.

전교 과목 확장

교수자가 과목별 AI 조교 정책과 자료를 설정할 수 있는 템플릿으로 확장합니다.

향후 팀 논의 체크리스트

팀원 의견을 받을 때 아래 질문에 답을 채우면 다음 버전 문서 업데이트가 빨라집니다.

  • 최종 제출 분야는 무엇으로 할 것인가?
  • 7개 중 하나를 단독 제출할 것인가, 메인과 확장 로드맵으로 묶을 것인가?
  • 실제 데모는 어떤 데이터로 만들 것인가?
  • 서강 특화 요소를 어떤 자료나 시스템과 연결해 보여줄 것인가?
  • 프라이버시, 평가 공정성, AI 오남용 방지 정책은 어떻게 설명할 것인가?
  • 발표 첫 30초에 심사위원을 붙잡을 Hook은 무엇인가?
